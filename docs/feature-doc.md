# UniApply — Feature Doc & Sprint Breakdown

## Roles
- **University** — creates profile, posts/edits/deletes circulars, manages applicants
- **Student** — builds profile, searches/filters/compares, applies, tracks status
- **Admin** — verifies universities, manages users, views analytics

## Full feature list

1. University Profile Management
2. Admission Circular Posting
3. Edit and Delete Circulars
4. University Dashboard
5. Applicant Management
6. Student Profile Setup
7. Online Application Submission
8. Document Upload
9. Application Dashboard
10. Application Status Tracking
11. Admission Search
12. Advanced Filtering
13. University Comparison Tool
14. Saved Universities
15. Student Eligibility Checker
16. Admin Verification System
17. Manage Users
18. Deadline Reminder Notifications
19. Application Update Notifications
20. Analytics Dashboard

## Sprint 1 — Setup & Auth (Owner: Sabit Irfan Ronve, 14 days)

| # | Feature | Functionality |
|---|---|---|
| 1 | University Profile Management | University fills in name, location, contact info |
| 2 | Admission Circular Posting | University creates/publishes a circular |
| 3 | Student Profile Setup | Student fills academic background & personal info |
| 4 | Online Application Submission | Student picks a circular and submits an application |
| 5 | Admin Verification System | Admin approves/rejects new university accounts |

## Sprint 2 — Core Features (Owner: Mantaka Mashiyat, 14 days)

| # | Feature | Functionality |
|---|---|---|
| 1 | Admission Search | Search circulars by university/program name |
| 2 | Edit and Delete Circulars | University updates or removes posted circulars |
| 3 | University Dashboard | Overview of active circulars + applicant counts |
| 4 | Document Upload | Student uploads transcripts/certificates/ID/photo |
| 5 | Application Dashboard | Student sees all submitted applications |

## Sprint 3 — Management Features (Owner: Umme Kulsum Prova, 14 days)

| # | Feature | Functionality |
|---|---|---|
| 1 | Manage Users | Admin views/deactivates/reactivates accounts |
| 2 | Advanced Filtering | Filter by degree level, department, location, deadline |
| 3 | Deadline Reminder Notifications | Daily check for circulars due within 3 days |
| 4 | Applicant Management | University reviews and updates applicant status |
| 5 | Application Status Tracking | Student views status history with timestamps |

## Sprint 4 — Advanced Features (Owner: Md. Nurul Asif, 14 days)

| # | Feature | Functionality |
|---|---|---|
| 1 | Saved Universities | Student bookmarks universities |
| 2 | University Comparison Tool | Side-by-side comparison of up to 3 universities |
| 3 | Application Update Notifications | In-app notification on status change |
| 4 | Analytics Dashboard | Admin views platform-wide stats & charts |
| 5 | Student Eligibility Checker | Compares student GPA against circular requirements |
